# 🏠 האפליקציה של לאוניד

אפליקציית נגישות עבור לאוניד - נכה צה"ל 100%+, דובר רוסית-עברית.

## ✨ מה כולל:
- 📅 **סידור עבודה חודשי** - עברית + רוסית (שמות: מטי, נתנאל, גומן, משה, סטס)
- 🏀 **כדורסל בני הרצליה** - אוטומטי מ-bhbasket.co.il + fallback ידני
- 💊 **טיפולים שבועיים** - בית הלוחם
- 🔊 **הקראה קולית** - עברית + רוסית

## 🏗️ מבנה הפרויקט:
```
leonid-app/
├── index.html                        ← הקובץ הראשי
├── shiftgen.html                     ← מחולל סידור עבודה חודשי
├── scripts/
│   ├── fetch_bhbasket.py             ← משחקים מ-bhbasket.co.il
│   ├── fetch_shiddurim.py            ← שידורי טלוויזיה מטלגרם (@Shiddurim, @sidorim)
│   └── update-basketball.js          ← טבלה ותוצאות
├── data/                             ← קבצי JSON שמתעדכנים אוטומטית
└── .github/workflows/                ← הרצה אוטומטית (GitHub Actions)
```

## 📋 עדכון סידור עבודה חודשי:
**הדרך הקלה:** פתח את `shiftgen.html` (באתר האפליקציה), לחץ "צור סידור", תקן ימים לפי הצורך, והעתק את הקוד שנוצר. ואז:

1. פתח את `index.html` ב-GitHub
2. לחץ על ✏️ (Edit)
3. חפש את `workSchedule`
4. הדבק את הקוד (או עדכן את התאריכים והשמות ידנית)
5. לחץ "Commit changes"

## 🏀 כדורסל:
GitHub Actions מריץ כל 6 שעות את הסקריפטים שבתיקיית `scripts/`, ושומר את הנתונים בתיקיית `data/`.
אם אין נתונים - יש fallback עם נתונים ידניים ב-`index.html`.
